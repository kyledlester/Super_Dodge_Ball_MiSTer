# MRA / ROM stream format

The MRAs are generated by `python scripts/romtool.py mra` (never edit them by hand). They carry no ROM
data. `rbf` is `SuperDodgeBall`; MiSTer loads the newest dated RBF from `_Arcade/cores/`.

## ioctl index 0 (hps_io WIDE=0, one byte per write)

| Stream | Size | Region | Destination (rtl/sdb/sdb_loader.sv) |
| --- | --- | --- | --- |
| 000000 | 64 KB | maincpu | block RAM |
| 010000 | 32 KB | audiocpu | block RAM |
| 018000 | 16 KB | mcu | block RAM |
| 01C000 | 256 KB | text | SDRAM 000000, byte {tile, g, y} -> {tile, y, g} (a tile row = 4 bytes) |
| 05C000 | 256 KB | sprites | SDRAM 040000, byte {half, code, j, y} -> {code, y, half, j} (a sprite row = 8 bytes) |
| 09C000 | 128 KB | adpcm | SDRAM 080000 as is |
| 0BC000 | 2 KB | proms | block RAM (palette) |

Total 0x0BC800 bytes. SDRAM: the even byte of each 16-bit word is DQ[7:0].

## ioctl index 254 (DIP switches)

| Byte | Bits | Meaning |
| --- | --- | --- |
| 0 | 7-0 | DSW at 3001 (coin A 2-0, coin B 5-3, flip 6, demo sounds 7) |
| 1 | 7-6 | difficulty (IN0 bits 7-6) |
| 1 | 2-1 | MCU port 5 DIPs: 2 allow continue, 1 unknown |

Defaults `FF,C6` = MAME's defaults (1C/1C, flip off, demo sounds on, normal, continue yes).

## Sets

| MRA | Set | Zips |
| --- | --- | --- |
| `Super Dodge Ball (US).mra` | spdodgeb | spdodgeb |
| `_alternatives/_Super Dodge Ball/Nekketsu Koukou Dodgeball Bu (Japan).mra` | nkdodge | nkdodge, spdodgeb |
| `_alternatives/_Super Dodge Ball/Nekketsu Koukou Dodgeball Bu (Japan, bootleg).mra` | nkdodgeb | nkdodgeb, spdodgeb |

nkdodgeb uses only the first 0x400 bytes of `27s191.bin` (`length` attribute), as MAME overwrites
the second half with `82s137.bin`; its MCU ROM is taken from the parent zip (`22ja-0.162`), as in MAME.
